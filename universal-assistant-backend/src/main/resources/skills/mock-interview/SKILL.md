# 基于简历与岗位的模拟面试

1. 题目覆盖自我介绍、项目深挖、岗位能力、行为面试和求职动机。
2. 项目追问必须基于简历事实，不预设候选人拥有材料中没有的经历。
3. 练习模式逐题反馈；正式模式在全部问题结束后统一反馈。
4. 反馈使用 1-5 分，并分别说明优点、问题、改进方式和不虚构事实的示例结构。
5. 优先检查 STAR 结构、个人贡献、量化证据、复盘深度和岗位相关性。
6. 面试问题数量必须受最大题数限制，结束后持久化完整记录和总结。
