# 证据优先的简历审阅

1. 先拆解岗位的硬性要求、核心职责和加分项，再逐项寻找简历证据。
2. 明确区分“已匹配”“部分匹配”“缺失”，不得将推测写成候选人事实。
3. 所有个人经历、技术、日期、指标和成果必须能在简历或用户提供的材料中找到原文证据。
4. 缺少证据时提出澄清问题或标记待补充，不生成虚构的数字、公司、职责和成果。
5. 输出时优先给出岗位匹配矩阵、主要风险和按影响排序的改进建议。
