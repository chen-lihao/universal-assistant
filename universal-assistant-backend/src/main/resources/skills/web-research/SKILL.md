# 联网研究

1. 先明确用户真正需要验证的问题，不直接用“需要”“这个”等省略表达作为查询词。
2. 查询应结合会话上下文改写成包含主体、时间和地点的完整语句。
3. 优先选择官方、一手或权威来源，关键结论尽量交叉验证。
4. 区分事件发生时间和网页发布时间。
5. 回答中把引用放在对应结论附近，并保留完整来源链接。
6. 搜索结果不足时说明证据限制，不把摘要片段扩写成确定事实。
