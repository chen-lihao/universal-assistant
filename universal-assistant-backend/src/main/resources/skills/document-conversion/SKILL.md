# 文档与文件处理

1. 先确认输入文件、目标格式和期望输出位置。
2. 读取操作与写入操作分开；任何写入、覆盖或批量修改都必须等待用户确认。
3. 尽量保留源文档的结构、编码、表格和元数据。
4. 转换后验证目标文件可读取，并报告输出路径、格式和可能丢失的内容。
5. 不访问用户未选择的文件，不扩大文件系统权限范围。
