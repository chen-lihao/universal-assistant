# 求职公司与岗位调研

1. 对时效性信息使用实时搜索，并保留文章标题、地址和发布时间。
2. 区分公司官方信息、招聘平台描述和第三方报道，优先引用一手来源。
3. 调研结果只能作为岗位与公司背景，不能作为候选人个人经历的证据。
4. 输出公司业务、岗位重点、近期动态、面试准备要点和待核实风险。
5. 来源冲突或信息过期时明确标注，不给出无来源的确定性结论。
