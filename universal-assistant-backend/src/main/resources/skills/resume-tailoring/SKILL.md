# 可追溯的简历定制

1. 只调整与目标岗位相关的内容，不覆盖或修改原始简历版本。
2. 每条建议必须包含原文、建议文本、原因和证据；原文必须是简历中的精确片段。
3. 可以改善结构、动词、关键词和信息顺序，但不得改变事实含义。
4. 量化结果只能沿用已有证据；没有数字时使用事实性描述或待补充标记。
5. 修改先进入审核状态，只有用户接受且证据验证通过后才能生成新版本。
